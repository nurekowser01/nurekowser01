# 💻 Software Engineering

Building scalable, maintainable, and highly-performant applications. While my infrastructure expertise ensures applications are resilient, my software engineering background ensures they are built correctly from the ground up.

## Core Development Principles
- **Clean Architecture:** Separation of concerns, interface-driven design, and dependency injection.
- **Test-Driven Development (TDD):** Writing robust unit, integration, and end-to-end tests.
- **Performance Optimization:** Efficient database querying, caching strategies (Redis), and minimizing algorithmic complexity.
- **API Design:** RESTful principles, GraphQL schemas, and secure authentication (OAuth2 / JWT).
