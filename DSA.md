# 🧠 Data Structures & Algorithms

A repository of algorithmic problem-solving, optimization strategies, and LeetCode pattern mastery. Writing code that simply "works" is only the first step; writing code that operates efficiently at scale requires a deep understanding of time and space complexity ($O(N)$).

## 🧩 Mastered Algorithmic Patterns

Rather than memorizing specific problems, I focus on the underlying patterns that solve broad classes of challenges.

### 1. Sliding Window & Two Pointers
- Efficiently parsing arrays and strings in $O(N)$ time.
- *Examples:* Longest Substring Without Repeating Characters, Container With Most Water.

### 2. Depth-First (DFS) & Breadth-First Search (BFS)
- Navigating trees, graphs, and matrices.
- *Examples:* Number of Islands, Word Ladder, Lowest Common Ancestor.

### 3. Dynamic Programming (DP)
- Optimizing recursive algorithms via memoization and tabulation.
- *Examples:* Knapsack Problem, Longest Increasing Subsequence, Coin Change.

### 4. Fast & Slow Pointers (Cycle Detection)
- Detecting loops in linked lists and arrays.
- *Examples:* Linked List Cycle, Find the Duplicate Number.

### 5. Binary Search (Advanced)
- Searching unsorted or rotated arrays efficiently in $O(\log N)$ time.
- *Examples:* Search in Rotated Sorted Array, Koko Eating Bananas.

## 🗃️ Core Data Structures

- **Linear:** Arrays, Linked Lists, Stacks, Queues
- **Hashing:** Hash Maps, Hash Sets (collision resolution strategies)
- **Trees:** Binary Trees, Binary Search Trees (BST), Tries (Prefix Trees)
- **Graphs:** Adjacency Lists, Adjacency Matrices, Directed Acyclic Graphs (DAGs)
- **Advanced:** Heaps (Priority Queues), Disjoint Sets (Union-Find)
